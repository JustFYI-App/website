Nous serions ravis d'avoir de vos nouvelles. Que vous ayez des questions, des commentaires ou besoin d'assistance, voici comment nous joindre.

## Support par e-mail

Pour les demandes generales, les demandes d'assistance ou les commentaires :

**E-mail** : [support@justfyi.app](mailto:support@justfyi.app)

### Ce qu'il faut inclure

Pour vous aider rapidement, veuillez inclure :

- Une description claire de votre question ou probleme
- Votre type d'appareil (Android ou iOS) et sa version
- La version de l'application (trouvee dans les Parametres)
- Des captures d'ecran pertinentes (assurez-vous qu'elles ne contiennent pas d'informations personnelles)

### Delais de reponse

Nous sommes une petite equipe travaillant sur Just FYI en tant que projet communautaire. Veuillez prevoir :

- **Demandes generales** : 2-3 jours ouvrables
- **Rapports de bugs** : 1-2 jours ouvrables pour la reponse initiale
- **Preoccupations de securite** : Sous 24 heures

Nous donnons la priorite aux communications liees a la securite et y repondrons aussi rapidement que possible.

## Rapports de bugs et demandes de fonctionnalites

Pour les problemes techniques, les rapports de bugs ou les suggestions de fonctionnalites, veuillez utiliser nos GitHub Issues :

**GitHub Issues** : [github.com/JustFYI-App/JustFYI/issues](https://github.com/JustFYI-App/JustFYI/issues)

### Signaler un bug

Lors du signalement d'un bug, veuillez inclure :

1. **Etapes pour reproduire** le probleme
2. **Comportement attendu** (ce qui devrait se passer)
3. **Comportement reel** (ce qui se passe reellement)
4. **Informations sur l'appareil** (modele, version du SE)
5. **Version de l'application**
6. **Captures d'ecran ou logs** si disponibles

### Demander une fonctionnalite

Pour les demandes de fonctionnalites :

1. Verifiez les issues existants pour eviter les doublons
2. Decrivez la fonctionnalite et son avantage
3. Expliquez votre cas d'utilisation
4. Soyez ouvert a la discussion et aux commentaires

## Vulnerabilites de securite

Si vous decouvrez une vulnerabilite de securite, veuillez la signaler de maniere responsable :

**NE CREEZ PAS** de GitHub issue public pour les vulnerabilites de securite.

Au lieu de cela, envoyez-nous un e-mail directement a **support@justfyi.app** avec :

- Objet : "Rapport de vulnerabilite de securite"
- Description detaillee de la vulnerabilite
- Etapes pour reproduire
- Evaluation de l'impact potentiel
- Votre correctif suggere (le cas echeant)

Nous prenons la securite au serieux et nous :

- Accuserons reception de votre rapport sous 24 heures
- Vous tiendrons informe de notre progression
- Vous crediterons dans nos notes de version (si vous le souhaitez)

## Ce avec quoi nous ne pouvons pas aider

En tant que projet axe sur la confidentialite, il y a certaines choses avec lesquelles nous ne pouvons pas aider :

- **Identifier les utilisateurs** : Nous n'avons pas acces aux identites des utilisateurs
- **Recuperer des donnees perdues** : Nous stockons les donnees des utilisateurs de maniere anonyme, mais nous ne pouvons pas identifier quel compte est le votre
- **Conseils medicaux** : Veuillez consulter des professionnels de sante
- **Affaires juridiques** : Nous ne pouvons pas fournir de conseils juridiques

## Questions frequentes sur le contact

### J'ai oublie mon identifiant anonyme. Pouvez-vous m'aider a le recuperer ?

Nous n'avons pas acces a votre identifiant anonyme. Il n'est stocke que sur votre appareil. Si vous en avez besoin d'un nouveau, vous pouvez generer un nouvel identifiant anonyme dans les parametres de l'application.

### Pouvez-vous me dire qui m'a envoye une notification d'exposition ?

Le systeme de notification est concu pour la confidentialite. Lorsque vous recevez une notification, vous verrez le nom d'utilisateur de la personne avec qui vous avez interagi (tel qu'enregistre au moment de l'interaction), mais seuls vous et cette personne savez pour votre interaction. Nous n'avons pas acces a ces informations.

### Mon application ne fonctionne pas. Que dois-je faire ?

1. Assurez-vous d'avoir la derniere version installee
2. Verifiez que le Bluetooth est active
3. Assurez-vous que l'application a les permissions necessaires
4. Essayez de redemarrer l'application ou votre appareil
5. Si les problemes persistent, envoyez-nous un e-mail avec des details

### Comment puis-je verifier que Just FYI est digne de confiance ?

Just FYI est source-available. Vous pouvez :

- Examiner notre code sur GitHub
- Verifier les audits de securite (si disponibles)
- Lire les avis des defenseurs de la vie privee
- Poser des questions dans notre communaute

Merci d'utiliser Just FYI et d'aider a construire une communaute plus sure et plus privee.
